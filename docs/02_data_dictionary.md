## Additivity rules

- **Flows** (every income-statement measure) can be summed over quarters (4 quarters = trailing twelve months) and across companies only when they report in the same currency.
- **Ratios** (margins, growth, tax rate) are non-additive: always sum the components first, then divide.
- **Semi-additive** measures (balances) do not occur in this dataset.
